# مقاطع النداء

تسجيلات النداء بأسمائها المذكورة في `AUDIO.md` بجذر المشروع.
القائمة كلها مُشتقّة من `client/src/audio-clips.js` — لا تُكتب باليد.

٤٣ ملفاً: ٣ ثابتة + ٣٠ رقماً + ١٠ غرف (`room-1` … `room-10`).
`chime.mp3` غائبٌ عمداً — المتصفح يولّد النغمة، وغيابها ليس نقصاً.
المقطع الناقص فعلاً يُستعاض عنه بالقراءة الآلية ويظهر في لوحة ⚙ على الشاشة.
